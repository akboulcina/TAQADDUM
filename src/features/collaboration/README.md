# Collaboration & Project Activity module

Named export:

```js
import { CollaborationModule } from './features/collaboration/CollaborationModule.jsx';
```

Props: `user`, `projects`, `activity`.

The module provides activity, discussions, announcements and follow-up views. Messages, tasks, read/unread states and selection are held in local React state. No API call, backend, authentication or database persistence is used.

All people, messages, announcements and tasks are fictional demonstration content and must not be presented as real CNED communications.
